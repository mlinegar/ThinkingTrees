\begin{abstract}
This minimal draft builds C-TreePO from one running example: estimating a
party manifesto's economic-policy position. We assume each span has a
task-relative economic state containing the evidence a trusted rubric oracle
would need, and we treat summaries as learned surrogates for that state. A
compression tree is valid when leaf summaries preserve span evidence, merges
preserve cross-span interactions, and re-summarization does not drift. Under
those local laws, work can move from whole manifestos to paragraphs, sections,
or chapters while preserving the document-level target. The main results give
root preservation, schedule invariance, DPO/GRPO-style objective equivalence,
and a sampled-audit preference-gap certificate. The main empirical section
leads with Manifesto economic measurement; Markov and HyperLogLog appear only
as short validation anchors, with full algebraic, proof, protocol, and
related-work detail deferred to appendices.
\end{abstract}
