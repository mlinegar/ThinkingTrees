\title{C-TreePO: Compression Trees for Oracle-Preserving Long-Document Learning}
\author{Mitchell Linegar}
\date{}

\begin{document}
\maketitle

\begin{abstract}
Researchers increasingly use large language models to measure long
political texts. Once a document exceeds the practical context
limit, the analyst no longer observes the original object: the
input to the final coding step is a compressed surrogate produced by
chunking, retrieval, or recursive summarization. Design-based
supervised learning shows that even highly accurate surrogate labels
can bias downstream estimates when substituted for gold-standard
labels \citep{EgamiEtAl2024}; in long-document settings the
surrogate is also the compressed representation, not just a
predicted label. We treat long-document coding as an
oracle-preserving compression problem on a tree. We partition
documents into contiguous spans, summarize them up the tree, and
audit each node locally for sufficiency, idempotence, and merge
consistency. Sampled oracle calls at any tree level (a leaf, a
paragraph, a section, or the full document) with logged propensities
turn compression-induced distortion into a finite-sample estimand
rather than assuming it away. The same design lets the analyst trade
one expensive full-document expert read for several cheaper reads of
shorter units and retain a comparable accuracy guarantee on the
document-level estimate. The same supervision design trains the
compression operators under a fixed audit budget; that is the
optimization side of the framework, the ``PO'' in C-TreePO. We test
the framework on the Manifesto/Benoit benchmark across six policy
dimensions: the C-Tree root scores match frontier LLM baselines and
each run leaves behind readable leaf, summary, and merge units for
sampled node audit.
\end{abstract}
