## Scope Notes

The Lean layer formalizes the algebraic and counting content needed by
mergeable-summary theory. It does not yet mechanize SQL parsing, null/ALL
catalog rules, physical array/hash/sort query plans, optimizer costs, or full
communication-complexity lower bounds for every SQL median/rank variant. The
Boolean median/majority finite-state lower bound is mechanized; broader SQL
rank/median lower bounds are separate parser, systems, and
information-complexity developments.
