# 16 Joint Tradeoff Matrix

This combines the dimensions instead of isolating them.

Goal:
- compare support, skew, and noise jointly
- hold the true target fixed at `1.0`
- show how the estimators behave when multiple problems happen at once

Run it:

```bash
venv/bin/python scripts/tutorial_supervision_16_joint_tradeoff_matrix.py
```
