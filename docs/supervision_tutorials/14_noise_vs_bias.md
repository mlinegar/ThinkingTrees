# 14 Noise Versus Bias

This separates two failure modes that are often mixed together.

Goal:
- keep the true target fixed at `1.0`
- compare four regimes:
  - unbiased + noiseless
  - unbiased + noisy
  - biased + noiseless
  - biased + noisy

Run it:

```bash
venv/bin/python scripts/tutorial_supervision_14_noise_vs_bias.py
```
