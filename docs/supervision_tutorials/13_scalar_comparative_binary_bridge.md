# 13 Scalar, Comparative, And Binary

This is the smallest example of “one supervision source, many optimizer views.”

Goal:
- start from scalar response scores
- derive one grouped comparative judgment
- derive binary projections from the same source
- show that scalar, comparative, and binary exports are just different views

Run it:

```bash
venv/bin/python scripts/tutorial_supervision_13_scalar_comparative_binary_bridge.py
```
